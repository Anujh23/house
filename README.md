# Kherla Ghar

Design for an east-facing G+1 family home near Pilani, Rajasthan.

**Live 3D model + floor plans:** https://anujh23.github.io/house/

- Vastu layout: parents' bedroom SW with an attached bath, kitchen SE, living + mandir NE, master bedroom stacked above the parents' room
- One 25½′ "sleeping-D" glass wall across the living and dining (north side)
- Built for Pilani's climate: big glass on the north and east, solid west wall, cool roof

`award-houses-inspiration.md` collects ideas from award-winning houses.
